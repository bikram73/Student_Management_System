Student Management System

The Student Management System is a compact, self-hosted admin tool aimed at small schools and instructors. It provides an easy way to manage student records, record daily attendance, and track test scores without requiring a database server — all data is stored in JSON files for simplicity and transparency.

Goals

  • Simplify daily attendance with a calendar view and per-day locking.
  • Support flexible test-score entry with dynamic inputs for multiple tests.
  • Keep deployment simple so it can run locally or on a small VM.
